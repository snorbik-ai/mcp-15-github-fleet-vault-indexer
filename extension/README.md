# Snorbik MCP 15 — Github Fleet Vault Indexer

Extension VSIX pour installer le MCP `15-github-fleet-vault-indexer` (runtime=python).

## Install MCP

Command Palette → **Snorbik MCP 15 — Github Fleet Vault Indexer: Install MCP (All Clients)** → Reload Window.

## Python minimum (si runtime=python)

Le VSIX embarque `bundled/python-embed` + `bundled/wheels` et matérialise `~/.snorbik/python-runtime`.

Réf. Article 04 / `07_REGLE_PYTHON_MINIMUM_ET_FABRICATION_EXTENSION_VSIX_v1.md`.
